# Avto Drom Avito Bot

Telegram-бот, который следит за объявлениями о продаже авто на [drom.ru](https://www.drom.ru/) и [avito.ru](https://www.avito.ru/) и присылает каждое новое объявление, подходящее под твои фильтры.

## Как добавить фильтр

Два способа:

1. **Ссылка.** Открой drom.ru или avito.ru, настрой марку/цену/год и прочее через фильтры на самом сайте, скопируй адрес страницы и пришли боту через команду `/add`.
2. **Анкета.** Команда `/add_form` — бот спросит площадку, марку, модель и диапазон цен и сам соберёт ссылку.

При первом подключении фильтра бот не присылает уже существующие объявления (их может быть сотни) — он берёт текущую выдачу за точку отсчёта и дальше шлёт только новые.

## Команды

- `/add` — добавить фильтр по ссылке
- `/add_form` — добавить фильтр через анкету
- `/list` — список фильтров, кнопка удаления
- `/cancel` — отменить текущий диалог добавления
- `/help` — справка

## Установка

Нужен Node.js 18+.

```bash
npm install
```

`npm install` сам скачает headless-браузер Chromium (через Playwright) — он нужен для обхода защиты Avito от простых запросов.

## Настройка

Скопируй `.env.example` в `.env` и впиши токен бота:

```bash
cp .env.example .env
```

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather) (команда `/newbot`)
- `POLL_INTERVAL_MINUTES` — как часто проверять фильтры, в минутах (по умолчанию 5)
- `DATA_DIR` — куда сохранять базу фильтров (по умолчанию `./data`)

## Запуск

```bash
npm start
```

Бот работает, пока запущен процесс. Для круглосуточной работы нужно оставить его на компьютере/сервере (например, через `pm2`, systemd-сервис или аналогичный windows-планировщик/NSSM).

## Важно про Avito

Avito активно защищается от автоматических запросов (капча, блокировка по IP). Бот открывает страницы Avito через настоящий headless-браузер, чтобы выглядеть как обычный посетитель, но:

- при подозрительно частых проверках Avito всё равно может временно заблокировать запросы — бот в этом случае пришлёт предупреждение в чат и попробует проверить фильтр позже, а не будет пытаться обойти капчу;
- не стоит ставить `POLL_INTERVAL_MINUTES` меньше 3-5 минут;
- чем больше активных Avito-фильтров, тем дольше идёт один цикл проверки (сайты проверяются по очереди с паузами).

Drom.ru таких проблем не создаёт — он отдаёт обычный HTML и проверяется простым HTTP-запросом.

## Данные

Фильтры и список уже увиденных объявлений хранятся в `data/db.json` (создаётся автоматически). Файл не нужно коммитить — он в `.gitignore`.
