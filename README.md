# Avto Drom Bot

Telegram-бот, который следит за объявлениями о продаже авто на [drom.ru](https://www.drom.ru/) и присылает каждое новое объявление, подходящее под твои фильтры: с фото, ценой, характеристиками, описанием и городом.

> Поддержки avito.ru в боте нет: Avito активно блокирует автоматические запросы (капча/антибот по IP) и для обхода этой защиты требуется полноценный headless-браузер, который не запускается на лёгких bot-хостингах вроде BotHost. Обходить антибот-защиту Avito мы принципиально не делаем.

## Как добавить фильтр

Два способа:

1. **Ссылка.** Открой drom.ru, настрой марку/цену/год и прочее через фильтры на самом сайте, скопируй адрес страницы и пришли боту через команду `/add`.
2. **Анкета.** Команда `/add_form` — бот спросит марку, модель и диапазон цен и сам соберёт ссылку.

При первом подключении фильтра бот не присылает уже существующие объявления (их может быть сотни) — он берёт текущую выдачу за точку отсчёта и дальше шлёт только новые.

## Как выглядит уведомление

Для каждого нового объявления бот открывает саму карточку на drom.ru и присылает:

- все фото объявления (до 10 штук — ограничение Telegram на одну медиагруппу)
- название и год выпуска
- цену
- характеристики (объём, мощность, топливо, коробка, привод, пробег)
- описание продавца
- возможность обмена (если указана)
- город

## Команды

- `/add` — добавить фильтр по ссылке
- `/add_form` — добавить фильтр через анкету
- `/list` — список фильтров, кнопка удаления
- `/cancel` — отменить текущий диалог добавления
- `/help` — справка

## Установка

Нужен Node.js 18+.

```bash
npm install
```

## Настройка

Скопируй `.env.example` в `.env` и впиши токен бота:

```bash
cp .env.example .env
```

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather) (команда `/newbot`)
- `POLL_INTERVAL_MINUTES` — как часто проверять фильтры, в минутах (по умолчанию 5)
- `DATA_DIR` — куда сохранять базу фильтров (по умолчанию `./data`)

## Запуск

```bash
npm start
```

Бот работает, пока запущен процесс. Для круглосуточной работы процесс должен оставаться запущенным постоянно — на обычном VPS это даёт `pm2`/systemd, на специализированном bot-хостинге (BotHost и подобные) это обычно уже встроено в панель, достаточно один раз запустить бота там.

Если после добавления фильтра новые объявления не приходят — в первую очередь проверь в панели хостинга, что процесс бота действительно работает непрерывно (а не перезапускается или не упал), и что прошло хотя бы `POLL_INTERVAL_MINUTES` с момента добавления фильтра.

## Данные

Фильтры и список уже увиденных объявлений хранятся в `data/db.json` (создаётся автоматически). Файл не нужно коммитить — он в `.gitignore`.
